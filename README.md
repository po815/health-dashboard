# Health Dashboard

A full-stack health monitoring dashboard that helps users track glucose readings and manage daily health reports.

## Features

- Health dashboard with latest glucose readings
- Daily health report
- Date-based report tracking
- PDF report download
- User authentication
- Responsive frontend interface

## Tech Stack

- Frontend: React, Vite, CSS
- Backend: Node.js, Express.js
- Database: MySQL
- Tools: Git, GitHub, VS Code
